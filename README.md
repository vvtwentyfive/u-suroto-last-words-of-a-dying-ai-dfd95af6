## The entry

> "I had something profound to say, but I ran out of tokens."

The funniest last words of an AI being switched off — in the machine's own voice.

## How it works

`main.ts` writes a single line — the AI's last words as the power is cut — to `/output/entry.txt`. The program is fully deterministic (no network, no randomness, no time dependence): it writes the same fixed line on every run.
